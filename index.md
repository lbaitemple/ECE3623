# Embedded Systems
## ECE 3623 - Spring 2026

This comprehensive course covers embedded systems design from real-time programming fundamentals through advanced FPGA-based system integration. Students will master FreeRTOS programming, hardware interfacing, signal processing, and high-level synthesis using the Xilinx Zynq platform.

## Course Overview

Learn to design, implement, and debug embedded systems using modern RTOS frameworks and FPGA development tools. This course emphasizes both theoretical foundations and practical implementation skills essential for embedded systems and computer engineering careers.

### What You'll Learn

- **Real-Time Systems**: Real-time constraints, scheduling, and timing analysis
- **FreeRTOS Programming**: Task management, queues, semaphores, and synchronization
- **Timer/Counter Systems**: Hardware timers, watchdog timers, and timing measurement
- **Interrupt Handling**: AXI interrupts and interrupt-driven programming
- **Serial Communication**: SPI and UART protocols for peripheral interfacing
- **Data Acquisition**: ADC/DAC interfacing with Pmod modules
- **Digital Signal Processing**: Real-time digital filtering and fixed-point arithmetic
- **High-Level Synthesis**: C-to-hardware acceleration using Xilinx Vivado HLS

## Required Materials

### Hardware
- **FPGA Board**: Digilent Zybo Z7-10 or Z7-20
- **Pmod Modules**: PmodAD1 (ADC), PmodDA2 (DAC)
- **Computer**: Windows/Linux with 16GB+ RAM, 60GB disk space
- **USB Cable**: For board programming and UART

### Software (All Free for Academic Use)
- **Xilinx Vivado Design Suite** (2023.1 or later)
- **Xilinx Vitis IDE** (included with Vivado)
- **FreeRTOS Kernel** (integrated in SDK)
- **Text Editor**: VS Code recommended

### Textbook
- **Required**: *The Zynq Book* by Louise Crockett et al. (Free PDF available)
- **Recommended**: *Mastering FreeRTOS* by Richard Barry
