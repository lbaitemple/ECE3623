## Overview

## SPI Protocol Fundamentals

### What is SPI?

**Serial Peripheral Interface (SPI)** is a synchronous, full-duplex communication protocol commonly used for high-speed data transfer between microcontrollers and peripherals.

### SPI Signals

```
┌─────────────────────────────────────────────────────────────────┐
│                        SPI BUS SIGNALS                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│      ┌────────────┐                    ┌────────────┐           │
│      │            │◄──── MISO ─────────│            │           │
│      │   MASTER   │───── MOSI ────────►│   SLAVE    │           │
│      │   (Zynq)   │───── SCLK ────────►│  (PmodAD1) │           │
│      │            │───── CS ──────────►│            │           │
│      └────────────┘                    └────────────┘           │
│                                                                  │
│  MOSI: Master Out, Slave In (data from master to slave)        │
│  MISO: Master In, Slave Out (data from slave to master)        │
│  SCLK: Serial Clock (generated by master)                       │
│  CS:   Chip Select (active low, selects slave)                  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### Key Characteristics

| Feature | Description |
|---------|-------------|
| **Type** | Synchronous, full-duplex |
| **Speed** | Up to 50+ MHz |
| **Data width** | Typically 8 or 16 bits |
| **Master/Slave** | Single master, multiple slaves |
| **Wiring** | 4 wires (minimum) |

## SPI Clock Modes

SPI supports four clock modes defined by **CPOL** (Clock Polarity) and **CPHA** (Clock Phase):

### Clock Mode Definitions

| Mode | CPOL | CPHA | Idle State | Sampling Edge |
|------|------|------|------------|---------------|
| 0 | 0 | 0 | Low | Rising |
| 1 | 0 | 1 | Low | Falling |
| 2 | 1 | 0 | High | Falling |
| 3 | 1 | 1 | High | Rising |

### Mode 0 Timing (Most Common)

```
CS   ─────┐                                         ┌─────
          └─────────────────────────────────────────┘

SCLK      ───┐   ┌───┐   ┌───┐   ┌───┐   ┌───┐   ┌───
             └───┘   └───┘   └───┘   └───┘   └───┘

MISO  ────┬───────┬───────┬───────┬───────┬───────┬────
          │ Bit 7 │ Bit 6 │ Bit 5 │ Bit 4 │ Bit 3 │...
          ↑       ↑       ↑       ↑       ↑       ↑
       Sample  Sample  Sample  Sample  Sample  Sample
       (rising edge)
```

## PmodAD1 Overview

### Features

The **PmodAD1** contains two Analog Devices AD7476A 12-bit ADCs:

| Specification | Value |
|---------------|-------|
| Resolution | 12 bits |
| Channels | 2 (independent) |
| Sampling rate | Up to 1 MSPS |
| Input voltage | 0 to VREF (typically 3.3V) |
| Interface | SPI |
| SPI Mode | Mode 0 or Mode 3 |

### Pinout

```
┌─────────────────────────────────────┐
│            PmodAD1                  │
├─────────────────────────────────────┤
│  Pin 1: CS1  (Chip Select Ch1)      │
│  Pin 2: D0   (MISO Ch1)             │
│  Pin 3: D1   (MISO Ch2)             │
│  Pin 4: SCLK (Serial Clock)         │
│  Pin 5: GND                         │
│  Pin 6: VCC  (3.3V)                 │
│  Pin 7: CS2  (Chip Select Ch2)      │
│  Pin 8: NC                          │
└─────────────────────────────────────┘
```

## AD7476 Data Format

### Conversion Timing

```
CS    ─────┐                                              ┌─────
           └──────────────────────────────────────────────┘

SCLK       ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
            └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └

MISO (D0)  ─X─X─X─X─┬───┬───┬───┬───┬───┬───┬───┬───┬───┬───┬─
            Leading │B11│B10│B9 │B8 │B7 │B6 │B5 │B4 │B3 │B2 │...
            zeros   │MSB│   │   │   │   │   │   │   │   │   │

           └──────────────── 16 SCLK cycles ────────────────┘
```

### Data Frame Structure

The AD7476 outputs 16 bits per conversion:
- Bits 15-12: Leading zeros
- Bits 11-0: 12-bit conversion result (MSB first)

## Zynq PS SPI Controller

The Zynq PS includes two SPI controllers (SPI0 and SPI1) in the APU.

### SPI Controller Features

| Feature | Description |
|---------|-------------|
| FIFO depth | 128 bytes (TX and RX) |
| Clock source | Configurable prescaler from IO PLL |
| Modes | Master/Slave, all 4 SPI modes |
| Chip selects | Up to 3 slave select lines |

### SPI Configuration Steps

1. Initialize SPI driver
2. Set master mode
3. Configure clock polarity and phase
4. Set clock prescaler for desired frequency
5. Enable chip select(s)

## SPI Driver Implementation

### Initialization

```c
#include "xspips.h"

XSpiPs SpiInstance;

int SPI_Init(void) {
    XSpiPs_Config *SpiConfig;
    int Status;
    
    // Look up configuration for SPI device
    SpiConfig = XSpiPs_LookupConfig(XPAR_XSPIPS_0_DEVICE_ID);
    if (SpiConfig == NULL) {
        return XST_FAILURE;
    }
    
    // Initialize the SPI driver
    Status = XSpiPs_CfgInitialize(&SpiInstance, SpiConfig,
                                   SpiConfig->BaseAddress);
    if (Status != XST_SUCCESS) {
        return XST_FAILURE;
    }
    
    // Perform self-test
    Status = XSpiPs_SelfTest(&SpiInstance);
    if (Status != XST_SUCCESS) {
        return XST_FAILURE;
    }
    
    // Set SPI options:
    // - Master mode
    // - Clock polarity (CPOL=0) and phase (CPHA=0) for Mode 0
    // - Manual chip select
    XSpiPs_SetOptions(&SpiInstance,
                      XSPIPS_MASTER_OPTION |
                      XSPIPS_FORCE_SSELECT_OPTION);
    
    // Set clock prescaler (SPI_CLK = SPI_REF_CLK / PRESCALE)
    // For 166.67 MHz ref clock and prescale 64: SPI_CLK ≈ 2.6 MHz
    XSpiPs_SetClkPrescaler(&SpiInstance, XSPIPS_CLK_PRESCALE_64);
    
    return XST_SUCCESS;
}
```

### Reading from PmodAD1

```c
#define PMOD_AD1_CHANNEL_0  0x00  // CS for channel 0
#define PMOD_AD1_CHANNEL_1  0x01  // CS for channel 1

uint16_t PmodAD1_ReadChannel(uint8_t channel) {
    uint8_t txBuffer[2] = {0x00, 0x00};  // Dummy bytes to generate clock
    uint8_t rxBuffer[2] = {0x00, 0x00};
    uint16_t adcValue;
    
    // Select the appropriate chip select
    XSpiPs_SetSlaveSelect(&SpiInstance, channel);
    
    // Perform SPI transfer (16 clock cycles)
    XSpiPs_PolledTransfer(&SpiInstance, txBuffer, rxBuffer, 2);
    
    // Extract 12-bit ADC value from received data
    // Bits 15-12 are leading zeros, bits 11-0 are data
    adcValue = ((rxBuffer[0] & 0x0F) << 8) | rxBuffer[1];
    
    return adcValue;
}

// Convert ADC value to voltage
float ADC_ToVoltage(uint16_t adcValue, float vref) {
    return (adcValue / 4095.0f) * vref;
}
```

## ADC Sampling with FreeRTOS

### Periodic Sampling Task

```c
#include "FreeRTOS.h"
#include "task.h"
#include "xil_printf.h"

#define ADC_SAMPLE_PERIOD_MS  100
#define VREF                  3.3f

void vADCSamplingTask(void *pvParameters) {
    uint16_t adcValue;
    float voltage;
    
    // Initialize SPI
    if (SPI_Init() != XST_SUCCESS) {
        xil_printf("ERROR: SPI initialization failed!\r\n");
        vTaskDelete(NULL);
        return;
    }
    
    xil_printf("ADC Sampling Task Started\r\n");
    
    for (;;) {
        // Read ADC channel 0
        adcValue = PmodAD1_ReadChannel(PMOD_AD1_CHANNEL_0);
        voltage = ADC_ToVoltage(adcValue, VREF);
        
        xil_printf("ADC Ch0: %d (%.3f V)\r\n", adcValue, voltage);
        
        // Delay until next sample
        vTaskDelay(pdMS_TO_TICKS(ADC_SAMPLE_PERIOD_MS));
    }
}
```

### Multi-Channel Sampling

```c
typedef struct {
    uint16_t ch0;
    uint16_t ch1;
    TickType_t timestamp;
} ADCSample_t;

QueueHandle_t xADCQueue;

void vDualChannelADCTask(void *pvParameters) {
    ADCSample_t sample;
    
    for (;;) {
        // Sample both channels
        sample.ch0 = PmodAD1_ReadChannel(PMOD_AD1_CHANNEL_0);
        sample.ch1 = PmodAD1_ReadChannel(PMOD_AD1_CHANNEL_1);
        sample.timestamp = xTaskGetTickCount();
        
        // Send to processing queue
        xQueueSend(xADCQueue, &sample, 0);
        
        vTaskDelay(pdMS_TO_TICKS(10));  // 100 Hz sampling
    }
}

void vDataProcessingTask(void *pvParameters) {
    ADCSample_t sample;
    
    for (;;) {
        if (xQueueReceive(xADCQueue, &sample, portMAX_DELAY) == pdPASS) {
            float v0 = ADC_ToVoltage(sample.ch0, VREF);
            float v1 = ADC_ToVoltage(sample.ch1, VREF);
            
            xil_printf("[%lu] Ch0: %.3fV, Ch1: %.3fV\r\n",
                       sample.timestamp, v0, v1);
        }
    }
}
```

## Protecting SPI Bus with Mutex

When multiple tasks access SPI, use a mutex for protection:

```c
SemaphoreHandle_t xSPIMutex;

void vTask1(void *pvParameters) {
    for (;;) {
        // Acquire SPI bus
        if (xSemaphoreTake(xSPIMutex, pdMS_TO_TICKS(100)) == pdTRUE) {
            // Perform SPI transaction
            uint16_t value = PmodAD1_ReadChannel(0);
            
            // Release SPI bus
            xSemaphoreGive(xSPIMutex);
            
            ProcessValue(value);
        }
        vTaskDelay(pdMS_TO_TICKS(50));
    }
}

int main(void) {
    // Create mutex before any SPI access
    xSPIMutex = xSemaphoreCreateMutex();
    
    // Create tasks
    xTaskCreate(vTask1, "Task1", 1024, NULL, 2, NULL);
    xTaskCreate(vTask2, "Task2", 1024, NULL, 2, NULL);
    
    vTaskStartScheduler();
    for (;;);
}
```

## High-Speed ADC Sampling

### Burst Sampling

For applications requiring high-speed data acquisition:

```c
#define BURST_SIZE  256

void vBurstSampleTask(void *pvParameters) {
    uint16_t samples[BURST_SIZE];
    int i;
    
    for (;;) {
        // Wait for trigger
        ulTaskNotifyTake(pdTRUE, portMAX_DELAY);
        
        // Burst sample (no delay between samples)
        for (i = 0; i < BURST_SIZE; i++) {
            samples[i] = PmodAD1_ReadChannel(0);
        }
        
        // Process burst data
        ProcessBurstData(samples, BURST_SIZE);
    }
}
```

## Error Handling

### SPI Transfer Errors

```c
int SPI_TransferWithRetry(uint8_t *txBuf, uint8_t *rxBuf, 
                           int len, int maxRetries) {
    int status;
    int retries = 0;
    
    while (retries < maxRetries) {
        status = XSpiPs_PolledTransfer(&SpiInstance, txBuf, rxBuf, len);
        
        if (status == XST_SUCCESS) {
            return XST_SUCCESS;
        }
        
        xil_printf("SPI transfer failed, retry %d\r\n", retries + 1);
        retries++;
        vTaskDelay(pdMS_TO_TICKS(1));
    }
    
    return XST_FAILURE;
}
```

### ADC Value Validation

```c
#define ADC_MIN_VALID  10     // Minimum valid reading
#define ADC_MAX_VALID  4085   // Maximum valid reading

uint16_t PmodAD1_ReadValidated(uint8_t channel) {
    uint16_t value = PmodAD1_ReadChannel(channel);
    
    // Check for stuck-at faults
    if (value < ADC_MIN_VALID || value > ADC_MAX_VALID) {
        xil_printf("WARNING: ADC reading out of range: %d\r\n", value);
        // Return previous valid value or handle error
    }
    
    return value;
}
```

## Summary

SPI is a high-speed synchronous protocol ideal for ADC communication. The PmodAD1 with its AD7476 ADCs provides 12-bit resolution at up to 1 MSPS. Proper integration with FreeRTOS requires consideration of task timing, mutex protection for shared bus access, and appropriate error handling. Understanding the AD7476 data format and SPI timing modes is essential for reliable data acquisition.
